**Aspirante a Cloud Networking** · Futuro estudiante de Telecomunicaciones y Servicios Digitales en INACAP Temuco · Chile

Tengo 18 años e ingreso a INACAP en 2027 para estudiar Telecomunicaciones y Servicios Digitales. Me estoy formando en redes, nube y automatización, con el objetivo de especializarme en **cloud networking**: el diseño, la seguridad y la automatización de redes en entornos cloud.

Sigo una ruta de estudio propia, con niveles y un criterio claro para avanzar: no paso al siguiente tema hasta cumplir una prueba práctica. Este perfil documenta ese proceso.

---

## Ruta de aprendizaje

Mi plan completo tiene 14 niveles. Estos son los principales:

| Etapa | Contenido |
|-------|-----------|
| Base | Linux y terminal, modelo OSI y TCP/IP, direccionamiento IP, subnetting, DNS, DHCP |
| Redes | Switching (VLAN, STP, EtherChannel), routing (estático, OSPF, BGP básico), ACL, NAT |
| Programación | Python, Git y GitHub, JSON y YAML, JavaScript básico |
| Automatización | APIs REST, Netmiko, NAPALM, Nornir, Ansible, Jinja2 |
| Nube | VPC y VNet, subredes, tablas de rutas, gateways, VPN, balanceadores, Transit Gateway |
| Infraestructura como código | Terraform, Ansible, Docker, Kubernetes |
| Seguridad y operación | Firewalls, segmentación, zero trust, CI/CD, observabilidad |

## Plan por fases
